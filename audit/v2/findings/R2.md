## 4. Schema finding blocks (severity changes)

### [LOW → recommend MEDIUM] L-15 — Oracle circuit-breaker check deleted; a clamped feed is served as a live price with no fallback
**Location:** `contracts/cap/oracle/ChainlinkAdapter.sol` (`price` — only `answer <= 0` rejected); `contracts/cap/oracle/Oracle.sol` (`_read`/`_fetchPrice` — secondary consulted only on 0/stale)
**Impact:** A Chainlink feed that has hit its `minAnswer` (LUNA-style) is accepted as the collateral price; every market using that collateral over-values it, so `healthiness` stays ≥ 1 while cUSD is unbacked, and a configured healthy secondary is never consulted. Round 1 rated this Low because the check existed and merely failed open when `aggregator()` was missing; now there is no check. Dollars at risk = full draw against the affected collateral.
**Likelihood:** Requires a real collateral crash below the feed floor (rare, but has happened: LUNA, and several stables' floors). No attacker action needed beyond borrowing at the stale floor; cost = 0.
**Exploit path:** (1) borrower posts collateral X, draws to `ltv`; (2) X crashes below `minAnswer`; (3) `Oracle.price(X)` returns the floor, `healthiness ≥ 1`, `liquidate` reverts `Healthy()`; (4) borrower keeps cUSD, tranches/cUSD holders absorb the difference on eventual write-off.
**Proof:** `audit/v2/tests/scratch/R2/oracle/L-15_CircuitBreaker.t.sol` — `test_L15_answerOnFloorServedAsLivePrice` (price == floor 1e18, secondary 1e14 unused), `test_H4a_…` (100e18 clamped answer accepted).
**Recommendation:** Restore a bounds check on each hop: if the hop exposes `aggregator()` with `minAnswer/maxAnswer`, treat `answer ≤ min` or `answer ≥ max` as invalid and fall to the secondary (treat a missing `aggregator()` as "no bounds published", not as pass). Include it in `setSource`'s dry run.
**Invariant broken:** none listed (oracle correctness precondition of I-health).

### [LOW, note] L-10 — round-1 demotion rationale is partly wrong on the new Stablecoin
Round 1 demoted L-10 on the basis that `totalAssets` is byte-identical with or without rolls.
