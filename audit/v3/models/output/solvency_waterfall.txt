== 3. Floor-to-zero dust rule (Tranche.slash L79-84): value lost per tranche per liquidation ==
  A request below one token unit converts to 0 assets and is passed on; after the senior it is uncollected.
  ETH 18-dec $2000  : max uncollected per tranche = 2000 wei USD = $2.00e-15   (price/10^decimals)
  WBTC 8-dec $60k   : max uncollected per tranche = 600000000000000 wei USD = $6.00e-04   (price/10^decimals)
  2-dec token $1    : max uncollected per tranche = 10000000000000000 wei USD = $1.00e-02   (price/10^decimals)
  => slashed < repaid*(1+bonus) by at most (n_tranches x price/unit): negligible unless the token has <= 2 decimals (P10).
